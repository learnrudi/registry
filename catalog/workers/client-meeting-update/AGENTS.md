# Client Meeting Update

This folder contains the Client Meeting Update worker skill.

Read [SKILL.md](SKILL.md) when asked to use, explain, or modify this worker. It
contains the complete goal, process and triggers, capabilities, context,
operating boundaries, run history and repair rules, and completion criteria.

walkthrough inside SKILL.md; real intake requires the configured accounts,
client context, and authority described there.
